# Ghost Racer Enhanced

Ghost Racer Enhanced 是一款 BeamNG.drive 圈速幽灵 Mod。它会记录你的行驶路线和圈速，让你在下一圈直接追逐之前的自己，并通过实时圈速差、速度对比和赛车线提示帮助你找到提升空间。

它适合赛道练习、自由驾驶环线、Hotlapping 和 Time Trial。默认线框 Ghost 是轻量视觉回放；
可选的 **Ghost body** 用车辆的静态车身网格（TSStatic，不参与物理）替代线框。它没有软体物理，
因此不会像原生车那样随时间累积帧率衰减，也不会撞击玩家或其他车辆；但每个车身仍有实际渲染开销，
数量多时会累积（车身总数有上限）。

> 本项目基于 **Jesus Goose** 的 **Ghost Racer Replay 1.6** 改进而来。请访问原作的 [BeamNG Resources 页面](https://www.beamng.com/resources/ghost-racer-replay.38554/)和 [BeamNG 论坛发布/讨论帖](https://www.beamng.com/threads/ghost-racer-replay.108045/)。感谢原作者提供这个项目的基础。

## 主要功能

- 在自由驾驶中设置起终点并自动记录连续圈。
- 实时显示圈速差 `Δt`、同位置速度差 `Δv`，以及对阵场上所有 Ghost 的实时名次 `RANK`。
- 每个起点分别保存最多 20 个完整圈、20 个未完成片段和 20 段手动录制；未完成片段按"跑了多远"保留（先淘汰最短的）。
- 通过两个正交维度组合显示：数量（最快圈 / Top N / 指定圈 / 多选圈 / 全部）× 类别（仅完成 / 仅未完成 / 两者）。
- 用颜色显示 Ghost 的速度、加速和制动变化。
- 显示完整最佳圈赛车线、路线带和沿途 Checkpoint。
- 在驾驶视角与 Ghost Chase / Onboard 视角之间切换。
- 保存多个可命名起点，换车或重开游戏后继续使用。
- 同一起点的 Ghost 和 PB 可以跨车辆共享，并保留每圈的录制车型。
- 可勾选最多五条记录，将紧凑 Ghost 分享码复制到系统剪贴板；分享码只能导入到匹配的地图与已保存起点。
- 自动接入 BeamNG Hotlapping 和 Time Trial。
- 提供完整 HUD，以及适合比赛时使用的圆形折叠仪表。

## 安装

1. 如果已经安装原版 Ghost Racer Replay，请先禁用它；原版和增强版不能同时启用。
2. 删除或移走旧的 `ghost-racer-enhanced-*.zip`，避免多个版本互相覆盖。
3. 将 `dist/ghost-racer-enhanced-2.17.2.zip` 放入 BeamNG 用户目录的 `mods` 文件夹。
4. 进入地图，打开 **UI Apps**，添加 **Ghost Racer Enhanced**。

更新 ZIP 后通常可以先按 `Ctrl+L` 重载 Lua，再按 `F5` 刷新 UI，无需立即重启游戏。HUD 标题中的 UI 版本和 Controller 版本应当一致。

## 快捷键（可选）

Ghost Racer 在 **Options > Controls** 中提供以下可绑定动作，方便不打开 App 也能操作（默认不绑定，自行分配以避免与游戏按键冲突；带门的动作仅自由驾驶有效）：

- **Set / restart lap start**：没有起点时在当前位置放起点门并开始一圈；已有起点时**在原地重开一圈**，不会移动或新建起点（等同 HUD 的 Set & start / Restart lap）。
- **Toggle auto lap**：武装 / 解除自动计圈。
- **Clear lap start**：停用当前起点的现场功能（Ghost 库保留）。
- **Set finish gate**：在当前位置放终点门，把该起点变成点对点（见下）。
- **Clear finish gate**：删除终点门，变回环线。
- **New track variant**：在当前起点位置新建一条赛道变体（见下）。
- **Toggle app mini / full size**：在完整面板和紧凑 mini 徽章之间切换 App（等同 HUD 上的 − / + 按钮）。

## 同点多变体（Track 变体）

一个起点位置可以挂多条**赛道变体（Track）**,每个变体有**自己独立的 ghost 库和终点门**。设好起点后,点 HUD 里的 **+ New track variant here**(或对应快捷键),在同一起点位置新建一条 Track,不影响原有的。此时会多出一个 **Track 下拉**:上面的 Saved Start 下拉选起点(位置),下面的 Track 下拉选该起点下的变体。适合在同一发车点跑多条不同的环线或点对点路线,各自独立记录 PB 和 ghost。旧起点会自动变成"单 Track"的起点,数据不受影响。删除当前选中的 Track 时,会自动选中同组里相邻的一条(优先上一条,若删的是第一条则选下一条);若删掉的是该组唯一一条,则不再有选中项。

## 点对点

默认起点是环线（过起点 → 再过起点计一圈）。开到你想设终点的位置，按 HUD 的 **Set finish** 按钮（或 Set finish gate 快捷键），在车头前放一个终点门，该起点就变成**点对点**：一圈从过起点计时到过终点。和未完成片段不同，点对点跑完会保存为**带真实用时的完整圈**并按 PB 更新幽灵回放，且不需要折返回起点。跑到一半再过起点会放弃本次、从起点重新开始。**P2P ✓** 表示已启用；赛道上会显示一个绿色的 **FINISH** 门标出终点位置。再点一下（或 Clear finish gate）删除终点门即变回环线。终点门几何随起点保存，重开或换车后仍在。

## 第一次使用

### 自由驾驶自动计圈

1. 把车停在计划使用的发车位置，车头朝向正常跑圈方向；起点门会自动放在车头前方约 5 米处。
2. 点击 **Set & start lap**。
3. 第 1 圈会立即开始录制。因为还没有历史记录，这一圈不会出现 Ghost。
4. 完整绕行并沿正确方向再次穿过起点后，第 1 圈会保存。
5. 第 2 圈会自动开始，同时播放刚刚完成的 Ghost。

分享记录时，点击 Ghost 行旁边的 `+`，最多勾选五条，然后点击 **Share**。应用会复制紧凑的 20 Hz 分享码，并通过 BeamNG Notice 显示复制状态和大小。2.19 起分享码会**一并携带驾驶输入**（油门/刹车/挡位/手刹/离合），导入后 Driver inputs 配色可用；更早版本导出的码不带输入，导入为纯轨迹（可正常回放，只是无输入配色）。导入前请先激活匹配的 Saved Start，再点击 **Import clipboard**。重复记录和未进入当前 Top 20 的慢圈会自动跳过；如果导入会替换现有完整圈或 Incomplete 记录，界面会先要求确认。

以后回到该地图时，可以从 **Saved Start** 选择原来的起点。已有 Ghost 的起点会先进入待命状态，下一次正确穿线时开始录制和播放。

起点一旦创建就**固定**：点 **Restart lap** 只是在原起点重开一圈，不会移动它，也不会新建起点线。想在别处新建起点，先点 **×** 停用当前起点，再到新位置点 **Set & start**。

### BeamNG Time Trial

进入 Time Trial 后，不需要手动设置起点。插件会在倒计时准备阶段按 Race 后缀或当前 Mission ID 生成一个 `tt-` 前缀的起点；较旧的活动没有这些字段时，会继续尝试 Race Path 和 BeamNG 发车位。比赛正式开始时，它会再次对齐 BeamNG 放置赛车的位置和朝向，把门放在车头前方约 5 米并按该位置的地面高度贴地。同一条 Time Trial 路线以后会更新并复用同一个起点，不会不断新增重复条目。

HUD 会将它显示为 **Time Trial Start / Auto**，两侧光柱也会出现在游戏选择的发车位。计时、环形赛道结圈和点到点终点仍由 BeamNG 的比赛系统判定，Ghost Racer 负责同步录制、播放和保存该路线的 PB/Ghost。

如果某个旧活动没有发送标准 Race 事件，插件会从当前前台 Time Trial Mission 主动建立同一个 `tt-` 起点。即使这个生命周期事件也缺失，在该活动中点击 **Set & start lap** 仍会现场识别 Mission，而不会创建普通的 `s001` 起点。

### 手动录制

不需要自动计圈时，可以点击 **Record** 开始或停止录制，再点击 **Play ghost** 手动回放。这种方式适合短距离路线、漂移路线或非闭合道路。

## Ghost 显示方式

显示由两个正交维度组合而成。

**数量**（显示哪些）：

- **Dynamic best**：始终显示最快圈。
- **Top N ghosts**：同时显示 Top 2、3、5 或 10。
- **Specified ghost**：只显示你指定的一圈。
- **Selected ghosts**：显示手动选择的多圈。
- **All ghosts**：显示所有可见 Ghost；数量很多时建议降低画质。

**类别**（Settings 中的 **Ghost recordings**，三选一）：

- **Completed**：只显示完整圈（默认）。
- **Incomplete**：只显示未完成片段。
- **Both**：同时显示两者。

两个维度自由组合，例如 Top 3 × Incomplete = 最长的 3 段残圈；Top 3 × Both = 最快 3 个完整圈**加**最长 3 段残圈（各取，最多 2N，因为圈速和长度无法混排，各按各的度量排名）。

如果一次录制因无效穿线、比赛结束、车辆重置（按 Insert 或 R）、切换起点或 30 分钟安全上限而中断，已有片段会以 `PARTIAL` 标记保存，并记录中断原因和时长。Completed 类别下这些片段隐藏，切到 Incomplete 或 Both 即可查看、选择、删除或回放。没有完整圈时，Dynamic best 会临时回放最长的可见片段；未完成片段仍不会成为 PB，也不会参与最佳圈赛车线、路线生成或完整圈排名。

三类记录使用独立容量，各 20 条：完整圈淘汰最慢的非 PB 圈；**未完成片段按跑了多远保留，先淘汰最短的（长度相同淘汰最旧的）**，因此失败尝试不会挤掉更有价值的长片段；手动 Run 淘汰最旧的。当按 R 存入的短片段比池里现存的都短时会被当场淘汰，此时提示会如实写明"未保留"，而不是谎称已保存。

想永久保留某条记录,点它那一行的 📌 **钉住**。钉住的 Ghost **不会被容量淘汰**,而且**不占用该类别的轮换名额**(相当于额外的保护槽);也**不能直接删除**,需先取消钉住。钉住状态随 Ghost 库一起保存,重载后仍在。

记录尚未播放时，列表中的 `PLAY` 会直接选择并回放该 Ghost（包括可见的 `PARTIAL`）；播放后按钮变为 `VIEW`，用于把视角切到对应 Ghost。点击 **DRIVER VIEW** 返回驾驶车辆。Ghost 不是实体车辆，因此不能使用 `Tab` 切换。

### 实时名次（RANK）

记圈时，HUD 会显示你在**当前赛道上所有 Ghost**（完整圈和未完成片段，不含手动 Run）中的实时名次，例如 `P3 / 12`（缩小模式下为角标 `P3/12`）。名次按"到位置用时"排定——和 `DELTA` 同基准：某 Ghost 到你当前位置用时更短就领先你。只统计当前显示、尚未跑完消失的 Ghost；`DELTA` 与 `SPEED Δ` 也以场上跑得最快那条（含未完成片段）为参照。

### Ghost body（车身网格）

Settings 中的 **Ghost body** 用车辆的静态车身网格（`TSStatic`，不参与物理）替代线框，默认关闭。它没有软体物理，因此不会像完整软体车那样随时间累积帧率衰减或造成长时间卡顿，可在所有显示模式下使用。但它仍是 `dynamic=1` 的逐对象渲染，每个车身都有实际的 CPU/GPU 开销，数量多时会累积；车身总数有上限，超出上限的 Ghost 仍以线框显示。具体数量对帧率的影响需在游戏内按机器实测（见 [`docs/ghost-body-perf-matrix.md`](docs/ghost-body-perf-matrix.md)）。它不能通过 `Tab` 进入。若某车型找不到可用的车身网格、或渲染握手失败，会保留/恢复稳定线框，不会回退去生成昂贵的完整车辆。

限制：静态网格只有车身，**没有车轮**，也**不半透明**（车漆材质不透明）；车身首次创建时可能有短暂加载停顿。需要车轮或半透明时才需要原生车辆，而原生车会带来物理开销。

## 赛车线与尾迹

在 Settings 中可以开启：

- **Show ghost trail**：显示 Ghost 身后的短距离遥测尾迹。在 Driver inputs 模式下,这条尾迹和最佳圈赛车线画法一致:主线只按油门/刹车上色,换挡是横向短标,离合(右)/手刹(左)是可选细副线(随各 Ghost 的名次亮度一起变暗)。因为镜头一直跟着 Ghost,即使只有几秒尾巴也能连续看出它在干什么。
- **Show best lap racing line**：显示完整最佳圈赛车线。
- **Absolute speed**：按绝对速度着色。
- **Acceleration / braking**：按加速、匀速和制动着色(由速度推算)。
- **Driver inputs**：按 ghost 驾驶员的**真实输入**着色。主线只显示 **刹车红、油门绿、双踩琥珀、滑行白**(踩得越深越亮);**换挡**在换挡点画一根**横穿线的短标记**(升挡粉 / 降挡紫);**离合**和**手刹**各是一条可选的细副线,分别在主线**右侧(离合青)**和**左侧(手刹蓝)**。可直观看出入弯拖刹、出弯何时接油门、在哪换挡、以及离合/手刹的使用。仅 2.18+ 录制的 ghost 带输入数据;更早的 ghost 在此模式下回退为 Acceleration 配色。
- **Show clutch sub-line**(在赛车线开关下方):在最佳圈线**旁边**画一条**更细的青色副线**,只在 ghost 踩离合处出现(踩得越深越亮),用来看起步/换挡/半联动而不挤占主线的油门刹车配色。默认关;更早录的 ghost 无离合数据、不画。
- **Show handbrake sub-line**(在赛车线开关下方):在最佳圈线**左侧**画一条**细蓝色副线**,只在 ghost 拉手刹处出现(拉得越狠越亮),适合看漂移/拉力。默认关(Driver inputs 模式)。
- **Show live input trail (debug)**:调测用——只要开着这个开关驾驶(自由驾驶也行),就在**你自己车后**实时画一条**和最佳圈赛车线完全一样画法**的输入轨迹:主线只有 红刹车/绿油门/琥珀双踩/白滑行,换挡是横向粉/紫短标,离合(右)和手刹(左)是可选细副线(和赛车线共用那两个开关)。边开边看自己的输入。显示最近的一段历史,按可设的**总段数上限**(100–2000)降采样(主线 + 换挡/离合/手刹叠加层合计不超过它);默认关,关闭开关时清除。
- **Automatic route guide**：根据参考圈生成路线带和 Checkpoint。

路线会尽量贴合地图道路。自定义赛道或没有导航道路数据的区域可能退回到原始 Ghost 轨迹，这不会影响录制、计圈或 Ghost 播放。

Checkpoint 采用与起点完全相同的光柱样式(两根干净的光柱、无连接横条)。**下一个**和**下下个** Checkpoint 会拔高到 60 米的醒目光柱,远处也能看清接下来的走线,其中下一个最宽、最亮。**车身真正穿过门线后**才变绿（已通过），下一个随即点亮。如果你**绕过**了某个还没通过的 Checkpoint(从门线旁边开过去),它会立刻变红,当场就知道这圈已作废,不用等回到起点。

当存在参考圈时，手动录制的圈会按路线校验：必须**按顺序通过每一个 Checkpoint**，回到起点才算有效圈。绕过（未在通过半径内经过）任意一个 Checkpoint 的圈不计成绩——会被直接丢弃并从起点重新开始一圈，提示里会写明漏掉的是哪个 Checkpoint。全新起点的第一圈没有参考，不做路线校验，照常记录。

最佳圈赛车线按**曲率自适应**降采样(Douglas–Peucker):弯道自动加密,紧弯保留远比固定间距更多的点;弯道再用 **Catmull-Rom 样条**(和 BeamNG 道路同类曲线)平滑成圆弧而不是折线,直道保持直线并切回熟悉的 6 米间距。超长赛道(约 24 km 以上)会自动放宽上限以守住段数上限,弯道细分也计入该预算。自动路线约每 10 米采样。绘制前逐点贴合地面;为保持帧率,只提交摄像机附近约 1.2 km 内的静态线段进行每帧绘制。100Hz 的原始录制不受影响,回放、时间差和名次均用全精度。

## 保存的起点和换车

起点按地图保存，不绑定某一辆车。切换车辆后，原来的起点、PB 和 Ghost 仍然可用；Ghost 列表会显示每圈由哪种车型录制。

从旧版本升级时，首次激活某个保存起点会自动合并过去分散在各车型目录中的记录。旧文件会保留作为恢复副本，重复换车不会反复导入同一圈。

可以重命名、停用或永久删除保存的起点。重命名成功时游戏会显示 BeamNG notice；永久删除需要先点击 `DEL`，再在确认时间内点击 `CONFIRM`，以避免误删整个起点的圈速记录。

## 常见问题

### 为什么第 1 圈没有 Ghost？

Ghost 必须来自一圈已经完成的记录。设置新起点后的第 1 圈用于建立参考，完成后会在第 2 圈自动出现。

### 为什么穿过起点却没有完成一圈？

请确认穿线方向正确，并且车辆没有从起点光柱范围以外经过。过短的圈、倒车穿线、重置或传送造成的大幅位置跳变也不会被计为有效圈。HUD 和 BeamNG notice 会显示拒绝原因。

### 为什么生成路线不是道路中心？

路线匹配依赖地图的导航道路数据。某些赛道网格、越野路面和自定义地图没有这些数据，此时会显示原始 Ghost 路线。

### 为什么 Ghost 看起来不像录制时的车辆？

跨车型使用历史记录时，位置和圈时来自原始记录，但线框外形会采用当前车辆的结构，以避免不同车型节点不兼容。

### 禁用 Mod 后 UI 仍然存在怎么办？

请通过 BeamNG Mod Manager 禁用或删除 Mod。重新载入 UI 后，Ghost Racer 会清理自己的布局项；重新启用时需要从 **UI Apps** 再次添加。

## 兼容性与限制

- 当前面向 BeamNG.drive 0.39 开发。
- 可以读取 Ghost Racer Replay 1.2 和 1.6 的旧记录。
- 旧格式没有速度数据，因此部分遥测信息可能显示为不可用。
- 线框 Ghost 和 Ghost body（静态车身网格）都不重放车轮转动、悬挂运动、车身变形或碰撞；Ghost body 还没有车轮、不半透明。
- 地图交叉路线、立交或分支道路可能让实时位置对比短暂匹配错误。
