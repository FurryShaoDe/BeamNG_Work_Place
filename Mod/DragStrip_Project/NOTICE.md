# NOTICE

This project is an unofficial add-on for BeamNG.drive. It is not affiliated with or endorsed by BeamNG GmbH.

## SSRB level dependency

This project targets the SSRB level mod ("Special Stage Route B"):

- Level identifier: `ssrb`
- Version referenced during research: `1.1`
- Repository resource id: `523`
- Authors listed in `levels/ssrb/info.json`: Nadeox1, DoullPepper

SSRB must be installed separately. No SSRB art, `.mis` scene file, `map.json`, or other SSRB files are redistributed in this repository. The add-on only adds new JSON files under new paths and refers to existing SSRB waypoint names (`wp2`, `wp3`) by name.

If SSRB is updated and its waypoint positions or road layout change, the coordinates in this add-on must be re-checked.

## BeamNG.drive

No BeamNG.drive game content is redistributed in this repository. The design refers to official Lua extension names, mission type names, and mission JSON structure for interoperability.
